# Portfolio Website

## Overview
This is a personal portfolio website designed to showcase my work, skills, and projects. The website features a modern design with a blue and black theme, smooth scrolling, and responsive layout.

## Project Structure
```
portfolio-website
├── src
│   ├── index.html          # Main HTML document for the portfolio website
│   ├── components
│   │   ├── header.html     # Navigation bar component
│   │   └── footer.html     # Footer component
│   ├── css
│   │   └── styles.css      # CSS styles for the website
│   ├── js
│   │   ├── main.js         # Main JavaScript file for global scripts
│   │   ├── nav.js          # JavaScript for navigation bar functionality
│   │   └── form.js         # JavaScript for handling contact form submission
│   └── data
│       └── projects.json    # JSON file containing project data
├── .vscode
│   └── settings.json       # VS Code specific settings
├── .gitignore              # Files and directories to ignore in version control
└── README.md               # Project documentation
```

## Features
- **Home Section**: A welcoming introduction to the portfolio.
- **About Me Section**: A brief overview of my background and skills.
- **Projects Section**: Dynamically loaded projects showcasing my work.
- **Skills Section**: A list of my technical skills.
- **Contact Section**: A form for visitors to get in touch with me.
- **Navigation Bar**: Smooth scrolling links to different sections and a "Download CV" button.
- **Responsive Design**: Optimized for various screen sizes.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the project in your preferred code editor.
3. Open `src/index.html` in a web browser to view the portfolio website.

## Running the Website
To run the website, simply open the `index.html` file in a web browser. For a better development experience, consider using a local server.
